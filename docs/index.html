How it works

One environment variable. That's the integration.

No SDK to import, nothing to wrap, no decorators to forget. Because it's a proxy, it works from any language and any client — Python, TypeScript, Go, curl.

STEP 01

Start the meter

Binds to localhost. Writes to a SQLite file in your home directory.

tokenmeter proxy
STEP 02

Point your app at it

The only line of your project that changes. Everything else runs as it did.

export ANTHROPIC_BASE_URL=\
  http://127.0.0.1:8787
STEP 03

Read the meter

Group by model, repo, branch, day, or your own tag.

tokenmeter report --by branch
your app ──► tokenmeter ──► api.anthropic.com │ └──► ~/.tokenmeter/usage.db
Why the cache gate exists

The regression a cost gate misses.

MetricBaselineCurrentChange
cost / call$0.015$0.016 +4.7%
cache hit rate88%16% −81.9%

Cost gate: passed. The build went green.

This showed up while testing the CI gate. Cost per call barely moved, so the threshold held and the build passed.

But the prompt prefix had broken, and cached tokens were quietly being repriced as fresh ones.

At that traffic volume it looked fine. At ten times the traffic it would not have been. A pure cost gate would never have caught it — which is why --max-cache-drop is its own gate, and why a collapse warns even when you haven't asked it to fail.

Cost regression testing

Fail the build before the bill.

Record a baseline on main, commit it, and let CI compare every pull request against it. The metric is cost per call, not total cost — total moves whenever you add a test case, so gating on it would flag new coverage as a regression. 

  METRIC                BASELINE  CURRENT  CHANGE
  cost / call            $0.0105  $0.0150  +42.9%
  input tokens / call       1.0K     1.6K  +60.0%
  output tokens / call       500      500    0.0%

  20 calls this run · 20 in the baseline

  FAIL  Cost regression detected.
        Cost per call rose 42.9%, over the 10% threshold.
--max-increase 10%

Cost per call rose more than 10% against the baseline.

--max-cost-per-call 0.05

Any run exceeds five cents per call, regardless of baseline.

--max-cache-drop 50%

Cache hit rate fell by more than half. The gate above.

--min-calls 20

Fewer than 20 calls recorded — catches a run where the proxy saw no traffic.

Privacy

It sits in front of your API key. So here's exactly what it does.

✓

Your key is forwarded, never stored

Credentials pass through untouched. They are never logged, written to disk, or inspected.

✓

Prompts are never read

Only token counts, model ids, and timing. Message bodies are forwarded as opaque bytes.

✓

Nothing leaves your machine

No account, no telemetry, no update check. The tool makes no outbound requests of its own.

✓

Metering can't break a request

Bytes are forwarded before they're measured. An accounting bug costs a data point, never a response.
